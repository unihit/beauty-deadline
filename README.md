# 뷰티기한 · 개인용 테스트 PWA

아이보리 배경과 차분한 그린 포인트의 모바일 중심 화장품 관리 앱입니다. 별도 AI API, API 키, 앱 로그인, 서버 저장, 동기화 없이 동작합니다. 호스팅의 소유자 전용 접근은 앱의 로그인과 별개입니다.

## 로컬 실행

Node.js가 있는 PC에서 이 폴더를 터미널로 열고 실행합니다. npm 패키지 설치는 필요하지 않습니다.

```powershell
npm start
```

PC 브라우저에서 http://localhost:4173 을 엽니다. 파일을 더블 클릭하는 file:// 방식은 IndexedDB·모듈·서비스 워커 사용 때문에 지원하지 않습니다. 테스트 서버는 실행한 터미널에서 Ctrl+C로 종료합니다.

휴대폰에서는 배포된 HTTPS 주소를 이용하세요. Android Chrome은 메뉴의 앱 설치, iPhone Safari는 공유 → 홈 화면에 추가를 사용합니다. 실제 Android/iOS 기기에 설치하는 과정은 미검증입니다. LAN의 일반 HTTP 주소에서는 PWA·오프라인 기능이 제한됩니다.

## 제공 기능

- 용기별 UUID로 사진·제품명·브랜드·카테고리·메모·상태·개봉일·사용기한·개봉 후 개월 수를 관리합니다. 날짜 없이 등록할 수 있습니다.
- 기준일은 표시된 사용기한과 개봉일 + 개월 수 중 빠른 날짜입니다. 월말은 대상 월의 마지막 날로 맞춥니다. 예: 2024-01-31 + 1M = 2024-02-29, 2026-08-31 + 3M = 2026-11-30.
- 미개봉 상태에서는 개봉 후 기간 계산을 적용하지 않습니다. 개봉일이 입력되면 사용 중으로 바꾸거나 날짜를 지우도록 안내합니다. 사용 완료·폐기는 현황 집계에서 제외됩니다.
- 기준일 당일은 30일 이내, 전날까지는 기한 경과, 30일 차이까지 임박, 그 이후는 여유로 분류합니다. 장치의 현지 날짜로 계산하며 앱에 돌아오면 갱신합니다.
- 검색·상태/카테고리 필터·기한/등록일/이름 정렬·현황별 빠른 필터를 지원합니다. 샘플은 명시적으로 선택하고 확인할 때만 추가됩니다.
- 사진은 긴 변 2200px 이하 JPEG로 저장합니다. 원본 해상도 보존용 서비스가 아닙니다. 입력 사진은 최대 20MB입니다.
- JSON에는 사진을 포함합니다. 복원 전 파일 형식·날짜·이미지·중복 ID를 검사하며, 같은 ID 덮어쓰기 수를 먼저 표시합니다. 복원은 IndexedDB의 단일 트랜잭션으로 처리합니다. 다른 ID의 기존 제품은 유지합니다. 최대 100MB/2000개 백업을 지원합니다.

## OCR과 검증 한계

Tesseract.js 5.1.1의 한국어+영어 모델을 사용합니다. 최초 엔진·WASM·언어 모델 다운로드에는 인터넷이 필요합니다. 브라우저가 사진을 직접 인식하며 외부 AI API로 사진을 보내지 않습니다. 엔진은 jsDelivr, 언어 모델은 Tesseract 기본 배포처에서 다운로드합니다. 한글 웹폰트는 Google Fonts에서 요청하고, 오프라인에서는 시스템 폰트를 사용합니다.

원문·제품명 후보·날짜 후보를 표시합니다. 후보는 자동 적용하지 않으며 별도의 적용/확인 절차를 거칩니다. 제조일 문맥 후보는 적용 버튼이 비활성화됩니다. 제조일을 입력하는 필드는 없고 계산에 사용하지 않습니다. OCR이 ‘제조’ 글자를 놓치면 후보가 종류 불명으로 나올 수 있으므로 실제 라벨의 EXP·사용기한을 사람이 확인해야 합니다.

지원 날짜 후보는 4자리 연도가 있는 YYYY.MM.DD, YYYY-MM-DD, YYYY/MM/DD, YYYY년 MM월 DD일 형태입니다. 두 자리 연도·MM/YYYY·숫자만 연속된 표기·로트코드 해독·제조일로부터 사용기한 추정은 제공하지 않습니다. 인식 실패 시 수동 입력할 수 있습니다.

실제 엔진을 실행해 합성 테스트 라벨 이미지의 `BEAUTY DAILY CREAM`, `EXP 2027.08.31`, `MFG 2026.08.31`, `12M` 원문 인식과 날짜 후보·제조일 차단을 확인했습니다. 실제 용기를 촬영한 사진은 제공되지 않아 검증하지 않았습니다. 곡면·반사·희미한 각인·작은 한글의 인식률을 보장하지 않습니다. OCR 오프라인 실행은 모델 캐시에 따라 달라지며 보장하지 않습니다.

공식 API 참고: https://github.com/naptha/tesseract.js/blob/master/docs/api.md

## 확인된 결과 (2026-10-27)

`npm test`: 6개 테스트 그룹 통과. 월말·윤년·잘못된 날짜·빠른 날짜 선택·미개봉 처리·정보 부족·0/30/31일 경계·제조일 후보·복원 입력 검사를 포함합니다.

실제 Chromium 브라우저에서 다음을 확인했습니다.

1. 빈 화장대 시작, 사진 포함 제품 등록.
2. 개봉일 2026-08-31 + 3M, 표시된 기한 2027-08-31 → 기준일 2026-11-30 및 근거 표시.
3. 새로고침 후 제품과 사진 유지, 제품명 수정 저장.
4. JSON 다운로드 → 제품 삭제 → 파일 선택과 미리보기 → 복원 → 새로고침 후 사진과 수정된 이름 유지.
5. 서비스 워커 활성화, 네트워크 오프라인 상태의 재접속 후 제품 표시.
6. 390×844 모바일 에뮬레이션에서 페이지 너비와 스크롤 너비 390px 일치. 데스크톱·모바일 스크린샷 별도 제공.

실물 Android/iPhone 설치·다양한 실제 사진 OCR·저장공간 한도까지의 대량 데이터·장기간 브라우저 자동 삭제 동작은 미검증입니다. 저장소 용량/권한 오류는 화면에 표시하며, 브라우저 데이터 삭제·기기 변경 전 JSON을 백업해야 합니다. 앱 종료 중 푸시 알림, 서버, 로그인, 기기 간 동기화는 구현하지 않았습니다.

## 직접 테스트

제품 등록 → 날짜를 비우고 저장 → 날짜 확인 필요 확인 → 기록 보기에서 개봉일/개월 수 수정 → 새로고침 → 백업 & 안내에서 JSON 다운로드 → 제품 삭제 → JSON 선택 → 복원 미리보기 확인 → 복원하기 순서로 확인할 수 있습니다. 같은 제품을 두 번 등록하면 서로 다른 용기로 보관됩니다. 초기 샘플은 자동으로 들어가지 않습니다.
